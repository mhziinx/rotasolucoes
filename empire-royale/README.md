# Empire Royale — Beta 0.1

Jogo mobile-first criado para a beta **Empire Royale**, com crédito de **mhzx**.

Inclui lobby, heróis com habilidades, loja, skins, moedas/diamantes de teste, música e efeitos via Web Audio, HUD touch, tiro, recarga, cura, habilidades, arena Canvas 2D, bots de simulação, zona, eliminações, ranqueado/RP, patentes, loading e configurações de qualidade/FPS.

Abra \`index.html\` ou publique esta pasta no GitHub Pages.

**Online real:** esta versão é o cliente jogável/MVP. Um Battle Royale competitivo precisa de servidor autoritativo, matchmaking, autenticação, persistência, sincronização em tempo real e anti-cheat; GitHub Pages não hospeda o servidor de partidas.
