# Rota — Agendamento | Soluções em Vidros

Site leve de agendamento e solicitação de orçamento da Rota.

## Estrutura
- `index.html` — página de agendamento
- `style.css` — visual responsivo
- `script.js` — formulário que abre o WhatsApp da Rota
- `assets/logo-rota.webp` — logo otimizada

O formulário pede nome, serviço, endereço e detalhes do atendimento. O envio abre o WhatsApp da Rota para continuar a conversa; não é necessário cadastrar o WhatsApp do cliente no formulário.
